# Junsong Wu

Research homepage: https://jason-wjs.github.io/

Static HTML and CSS. GitHub Pages publishes the root of the `main` branch. `.nojekyll` disables Jekyll processing.

For local preview, run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory.

Adapted from [Jon Barron’s academic website](https://github.com/jonbarron/jonbarron.github.io); attribution remains in the footer. Lato fonts are distributed under the included SIL Open Font License.

Research videos are short, silent excerpts from the corresponding public project demonstrations. The NEXUS excerpt uses 36.25–43.55 seconds of [the project demo](https://www.youtube.com/watch?v=2J9YmBuMFoc), cropping its lower-left view to retain the operator, humanoid and stair platform.
